# Model weight licenses

The team-trained checkpoints and exported selectors, including the six
three-verifiers files in `release_weights.sha256`, use Creative Commons
Attribution-NonCommercial 4.0 International. Attribute the Solar
Filament Segmentation Challenge 2026 contributors and the MAGFiLO
dataset used for training. [CC BY-NC 4.0 legal code](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en)

MAGFiLO v1.0 is described by Azim Ahmadzadeh and colleagues in *Scientific Data* 11, 1031 (2024). The underlying H-alpha observations are from the National Solar Observatory's Global Oscillation Network Group. [MAGFiLO data descriptor](https://doi.org/10.1038/s41597-024-03876-y) · [NSO GONG H-alpha data](https://nso.edu/data/nisp-data/h-alpha/)

## Afshar public U-Nets

public-ensemble also uses ten public U-Net checkpoints by Dariush Afshar, five
ResNet-34 and five EfficientNetV2-S folds. The upstream files use
Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International.
The original checkpoints, ensemble receipt, and upstream README are
included under [`weights/public/`](weights/public). Retain Afshar's credit, source and license when
redistributing those files. [Afshar's Kaggle dataset](https://www.kaggle.com/datasets/dariushafshar/solar-filament-unet-weights) · [CC BY-NC-SA 4.0 legal code](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en)

The original source code uses the separate [MIT License](LICENSE).
Dependencies and pretrained initializers retain their upstream terms.
